## ADDED Requirements

### Requirement: GenerateContentPart carries source ID

The `GenerateContentPart` struct SHALL include an `ID` field (`id` JSON tag, omitempty) so that non-streaming source entries can carry a unique identifier matching upstream `LanguageModelV4Source`.

#### Scenario: Non-streaming citation source has ID
- **WHEN** `convertResponse` processes a text block with citation references
- **THEN** each `GenerateContentPart` of type `source` SHALL have a non-empty `ID` generated by `generateID()`

#### Scenario: Non-streaming web search source has ID
- **WHEN** `convertResponse` processes a `web_search_tool_result` content block with search results
- **THEN** each `GenerateContentPart` of type `source` SHALL have a non-empty `ID` generated by `generateID()`

#### Scenario: Non-source content parts unaffected
- **WHEN** a `GenerateContentPart` has type `text`, `tool-call`, `tool-result`, or `file`
- **THEN** the `ID` field SHALL remain empty and SHALL be omitted from JSON serialization

### Requirement: Streaming web search sources carry ID

The `emitWebSearchResult` function SHALL set `ID` on every `SourceInfo` emitted for web search results, using the adapter's `generateID` function.

#### Scenario: Streaming web search source has ID
- **WHEN** `emitWebSearchResult` emits `SourceInfo` entries for each search result in a `web_search_tool_result` block
- **THEN** each `SourceInfo` SHALL have a non-empty `ID` generated by `a.generateID()`

#### Scenario: Streaming citation sources unaffected
- **WHEN** `citations_delta` events produce source entries via `createCitationSource`
- **THEN** those sources SHALL continue to receive their ID from `createCitationSource` (no change)
