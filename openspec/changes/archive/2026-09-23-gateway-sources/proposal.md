## Why

WP19 (#113) permits clients to receive URL/document sources through the strict Gateway. WP7 and WP8 are present; this work is independent of file, reasoning and provider-tool transport.

## What Changes

- Add bounded explicit source DTOs, response-local identity and closed public citation metadata.
- Decode both variants in the independent Apache Go client.
- Cover native OpenAI sources through authenticated command tests, reusable observation and UI assembly.
- Preserve Title-first compatibility and neutralize native file_path display identity at the Gateway boundary.

## Capabilities

### New Capabilities

- `gateway-sources`: Source output, privacy, lifecycle and cross-client evidence.

### Modified Capabilities

- `providerwire-v4-streaming-runtime`: Sources are supported atomic output.
- `providerwire-v4-unary-runtime`: Sources extend the normalized unary subset.
- `grafana-gateway-client`: Independent source consumption.

## Impact

AGPL DTOs, schemas and service tests remain under ai-gateway. Apache client and observer changes remain independent. No provider recordings, root workspace registration or committed replacements are added. Published observer adoption is a separate consumer-pin step; local overlay evidence does not prove deployed timing changes.
