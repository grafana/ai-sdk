## Context

Registered `@ai-sdk/gateway` 4.0.96 forwards `includeRawChunks` when the caller sets it (`streamText` always does), and its stream transform yields `{type:"raw",rawValue}` parts only when the caller asked. It has no unary raw part. The Go client in `providers/grafana` already sends the flag, decodes `raw` events, filters them the same way, and rejects a raw event without `rawValue`. The TS client forwards any parsed object. The Anthropic and OpenAI adapters emit `PartRaw` only when `IncludeRawChunks` is true, with a nil value for a native frame that was not valid JSON.

## Decisions

- **Who may request raw output.** Any authenticated caller. The issue says "requested and allowed"; the Gateway already authenticates every call, and no operator has asked to restrict it. The per-candidate execution policy seam (`nativeOptionsModel` returning `catalog.ErrUnsupportedRequest`) can reject the flag later, for example on compatible routes, without changing the wire format. Per-caller or per-route switches would need new configuration; none exists to reuse.
- **Unary.** The flag is accepted and passed through; the result is unchanged. Native unary bodies remain with the developer-evidence work (#323).
- **Filtering.** The handler writes a raw part only when the request set the flag, so an adapter that emits raw parts unconditionally cannot leak them. Nil or invalid values are dropped because a LanguageModelV4 raw part requires a value and the Go client rejects a raw event without one. Adapters check JSON syntax only, and Go accepts invalid UTF-8 there, so values that are not UTF-8 are dropped too. Otherwise the frame encoder would fail a stream that succeeds without the flag.
- **Size.** Upstream has no per-event limit to follow: the registered `@ai-sdk/gateway` client parses SSE without a size check and delivers raw events of any size, and the hosted Gateway's rule is not public. `StreamFrameBytes` and the Go client's `StreamEventBytes` are Grafana resource bounds, so this is a Grafana decision, not a parity one. Raw events use the existing `StreamFrameBytes` preflight. An oversized event ends the stream with one internal error, as for any other oversized frame. The #321 omission rule covers developer evidence, not stream frames, and silently dropping one event would make the raw sequence look complete when it is not. A large `response.completed` can exceed the default 1 MiB frame. Raising it needs both the Gateway's `StreamFrameBytes` and the Go client's `Limits.StreamEventBytes`, which also defaults to 1 MiB.
- **Part budget.** Raw parts count toward `StreamParts` before filtering, as every part already does, so requesting raw output roughly halves the usable normalized part budget for OpenAI streams.
- **Credentials.** OpenAI Responses `response.created`/`response.completed` echo request `tools`. For MCP tools that includes `headers` and `server_url`; OpenAI documents that `authorization` is not returned, but it is removed if present. Following the #321 source rules, the handler nulls header values and strips `server_url` userinfo and documented auth query keys. Every value is decoded, so escaped key spellings are seen, and every object typed `mcp` is projected wherever it appears. A `server_url` whose URL or query does not parse is removed, since it cannot be shown to be credential free. A value that repeats an object key is dropped: readers disagree on which duplicate wins, so a projected copy could still show another reader the credential. Values keep their JSON meaning, and numbers keep their digits through `UseNumber`, but frame encoding compacts whitespace and escapes HTML characters, and a projected value comes out with sorted keys. Raw events do not match provider bytes exactly. This projection is narrow and can be replaced by the shared projection from #373.
- **Telemetry.** The Gateway logger, Prometheus metrics and metadata-only Agent Observability do not record raw values; a test pins this.

## Risks

Other providers may echo credentials in raw events the projection does not know about. The Gateway serves Anthropic, OpenAI and OpenAI-compatible adapters. Anthropic does not echo request tools. The compatible adapter emits a raw part for every data frame from whatever backend an operator configures, and those shapes are not reviewed here.

Native error frames (Anthropic `error`, OpenAI `error` and `response.failed`, compatible error chunks) reach a caller who requested raw output unchanged, while the Gateway's own error events keep reducing upstream failures to safe messages. Those native messages can name the operator's provider account or limits. Whether that is acceptable for raw output is a maintainer decision.

Raw events expose native provider shapes that can change without notice. They are diagnostic output, not a stable contract.
